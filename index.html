One job

Schema in the database, so agents do not reinvent your domain

When agents need operational knowledge, I want a model the database enforces, so I can stop re-encoding domain rules in prompts and application code.

Retrieval is not the same as a model. RAG and property graphs return neighbors. The agent still invents structure: which things can connect, which roles they play, which writes are invalid.

TypeDB keeps that model in the database. Entities, n-ary relations, and attributes are typed. A bad write fails here. Agents query the same schema in TypeQL.

This page does not claim that agents never invent facts, or that Cluster is generally available.
